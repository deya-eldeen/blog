Networking in Swift and iOS

HTTP clients with clear contracts for failure, freshness, and cancellation

Build networking features from HTTP fundamentals through real application lifecycles. The topics move from what URLSession puts on the wire, through client design, authentication, and resilience, to transfers, live connections, testing, and diagnosis. Each article measures the behavior it describes and ends with an exercise.

The examples use Swift 6 language mode and were compiled and run with the Swift 6.4 toolchain from Xcode 27.1 on macOS 26. Most of them talk to LocalServer, a small HTTP/1.1 server on the loopback interface whose source is in the appendix of the first article, so that every claim about redirects, retries, caching, timeouts, and streaming is checked against real requests. The testing articles are Swift packages run with swift test, and the iOS-only code in the background transfers article was compiled against the iOS 26 SDK.

Diagrams show request sequences, state machines, and timelines; equations appear where they give a precise answer, such as how many connections a burst needs, how much jitter flattens a retry storm, or how many requests coalescing saves. The concurrency roadmap covers the language features these articles rely on.
