RxSwift

The reactive library that powered a generation of iOS apps

RxSwift is the Swift member of the ReactiveX family, the same reactive programming model available in many other languages, such as RxJava and RxJS. It treats events, user input, and network responses as observable sequences that you transform and combine with operators.

RxSwift came years before Apple’s Combine, and it’s still in many production apps. Even if you start new projects with Combine or Swift concurrency, knowing RxSwift will help you work with existing codebases, and the concepts transfer almost one to one.

Each article measures the behavior it describes and ends with an exercise. The examples use RxSwift 6.10.2 in Swift 6 language mode and were compiled and run with the Swift 6.4 toolchain from Xcode 27.1 on macOS 26, so they also show where RxSwift, a library compiled without strict concurrency checking, meets Swift 6’s actor isolation: which closures crash when a chain delivers on a background thread, and how to write chains that do not. Time-based behavior is measured on RxTest’s virtual clock, set up in the filtering article; the RxCocoa and MVVM examples ran against real UIKit controls in the iOS simulator; and the testing article is a Swift package run with swift test.
