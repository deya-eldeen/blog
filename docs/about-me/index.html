Hi, I’m Deya 👋

I’m a mechatronics engineer who fell in love with code, and never quite fell out of it. These days I’m a senior iOS developer, and Swift By Deya is where I take the things I learn at work, in side projects, and down late-night rabbit holes, and turn them into articles I wish I’d had when I started.

How It All Started 🎮

I was 13 when I opened the Blender game engine for the first time and started building 3D games. What began as a hobby quickly turned into a job: I worked as a full-time game developer all through college, back before the iPhone and Android even existed.

Games taught me lessons that still shape how I write software today: performance matters, details matter, and if something feels wrong to the player, it is wrong.

From Games to iOS 📱

Somewhere along the way, the pixels led me to iOS. Engineering gave me the habit of understanding how things work under the hood, and games gave me an obsession with how things feel. Apple’s platforms turned out to be the perfect place for both.

What You’ll Find Here 🧭

This blog is mostly about Swift and iOS, with a soft spot for the topics that make code genuinely better:

  • Swift, deep and practical: language features, generics, memory, and the “why” behind the “how”.
  • Algorithms, data structures, and design patterns, explained with real Swift examples.
  • Security, testing, and accessibility: the things that separate an app that works from an app people can trust.
  • Different programming paradigms, because the best tool depends on the problem.

New here? Start with the latest articles, browse the full archive, or follow the iOS roadmap, a structured path through everything a Swift developer needs to know, from the language basics up.

Books I’ve Written 📚

Sometimes a topic is too big for a blog post:

  • iOS Security Through Defensive Techniques, co-written with Dave Poirer, is a practical guide to protecting iOS apps against insecure data storage, reverse engineering, and runtime tampering.
  • Byte Magic In Swift takes bitwise operators from the fundamentals to real-world Swift use cases, with 95+ examples.

You can also see the apps, libraries, and open-source projects I’ve built in my portfolio.
