Sensors and Location in iOS

Turn device signals into useful features while respecting accuracy and energy

Work with motion, location, and environmental measurements as fallible streams of data. The series covers permissions, coordinate systems, signal quality, and lifecycle cleanup, and each article ends with an exercise.

Every claim is measured. The examples use Swift 6 language mode and were compiled and run with the Swift 6.4 toolchain from Xcode 27.1. Core Location and Core Motion code ran in an app-hosted test bundle on an iPhone 17 simulator running iOS 27.0, with routes scripted by simctl and the real permission alerts and Settings switches tapped by a UI test. The simulator has no motion sensors, so the motion articles pair Apple’s documented behavior with simulations from stated sensor models, each checked against the formula it should reproduce, and the simulator article lists what still needs a device. The testing articles are Swift packages run with swift test.
